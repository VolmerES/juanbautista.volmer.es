mini_serv

Escribe un programa que funcione como un servidor de chat usando sockets TCP.

El servidor debe:

  • Aceptar conexiones de múltiples clientes
  • Asignar un ID incremental a cada cliente
  • Reenviar los mensajes de cada cliente a todos los demás
  • Notificar cuando un cliente se conecta o desconecta
  • Usar select() para I/O multiplexing
▶ Funciones permitidas
  • write, close, select
  • socket, accept, listen, send, recv, bind
  • strlen, strcpy, strcat, sprintf
  • calloc, realloc, free, malloc
  • bzero, htonl, htons, atoi
  • exit
▶ Mensajes requeridos

"Wrong number of arguments\n" → stderr, si argc != 2

"Fatal error\n" → stderr, ante cualquier error fatal

"server: client X just arrived\n" → al conectarse

"server: client X just left\n" → al desconectarse

"client X: "<msg> → al reenviar mensaje

▶ Código dado: extract_message

Esta función extrae un mensaje completo terminado en '\n' del buffer de un cliente.

int extract_message(char **buf, char **msg)
{
    char *newbuf;
    int i = 0;

    *msg = 0;
    if (!*buf)
        return (0);
    while ((*buf)[i])
    {
        if ((*buf)[i] == '\n')
        {
            newbuf = calloc(1, strlen(*buf + i + 1) + 1);
            if (!newbuf)
                return (-1);
            strcpy(newbuf, *buf + i + 1);
            *msg = *buf;
            (*msg)[i + 1] = 0;
            *buf = newbuf;
            return (1);
        }
        i++;
    }
    return (0);
}
▶ Código dado: str_join

Concatena el buffer previo con lo recién leído.

char *str_join(char *buf, char *add)
{
    char *newbuf;
    int len = buf ? strlen(buf) : 0;

    newbuf = malloc(len + strlen(add) + 1);
    if (!newbuf)
        return (0);
    newbuf[0] = 0;
    if (buf)
        strcat(newbuf, buf);
    free(buf);
    strcat(newbuf, add);
    return (newbuf);
}
